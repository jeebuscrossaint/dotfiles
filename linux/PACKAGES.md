# Packages

Artix (runit), Arch repos via `artix-archlinux-support`. 199 explicitly installed
— 175 native, 25 AUR — of ~1131 total once dependencies are counted.

Reinstall:

    sudo pacman -S --needed - < linux/packages/native.txt
    paru      -S --needed - < linux/packages/aur.txt

`native.txt` and `aur.txt` are generated, not curated:

    pacman -Qqen | sort > linux/packages/native.txt
    pacman -Qqm  | sort > linux/packages/aur.txt

Regenerate them after installing something you mean to keep. Everything below is
the curated view of the same data — which packages this repo's configs actually
depend on, which are just installed, and which are neither.

## Everything else

The remaining explicit packages are system and toolchain, not dotfiles: runit
service packages (`*-runit`), kernels and firmware (`linux`, `linux-lts`,
`linux-firmware`, `intel-ucode`, `sof-firmware`), Artix tooling (`artools-*`,
`artix-*`), virtualisation (`qemu-system-x86`, `podman`, `docker`, `edk2-ovmf`,
`virtiofsd`), and assorted CLI toys (`cbonsai`, `cmatrix`, `pipes-rs`, `genact`,
`pscircle`). See `linux/packages/native.txt` for the full generated list.
