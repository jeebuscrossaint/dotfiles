# dotfiles

mango · conky · kitty · fish · micro · fuzzel · dunst · swaylock · [coat](https://github.com/jeebuscrossaint/coat)

arch linux

```sh
git clone https://github.com/jeebuscrossaint/dotfiles ~/dotfiles
~/dotfiles/install.fish
```

Installs the packages, links `linux/` into `~`, applies coat. `-h` for options.

## minecraft

1.8.9 PvP in PrismLauncher, mods in `minecraft/mods.txt`.

```sh
./install.fish --minecraft
```

## windows

```powershell
Set-ExecutionPolicy -ExecutionPolicy RemoteSigned -Scope CurrentUser
Invoke-RestMethod -Uri https://get.scoop.sh | Invoke-Expression
scoop install pwsh uutils-coreutils git bat fastfetch gh
.\install.ps1
```
